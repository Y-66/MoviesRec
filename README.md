# MoviesRec

Movie recommendation data processing project.

## Directory Structure

* `src/`: Main source code (scripts, modules)
* `data/`: Raw and processed data files (CSV, DB)
* `tests/`: Unit tests
* `docs/`: Documentation and notes

## Setup

1. Install dependencies and project in editable mode: `pip install -e .`
2. Run data processing script: `python script.py` (consider moving to `src/`)
