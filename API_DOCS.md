# Movies Recommendation Agent API Documentation

This document describes the REST API endpoints for the Movies Recommendation API powered by FastAPI and LangGraph.

Conversation memory in one server session is managed by LangGraph checkpointer (thread-level memory).

History files under `chat_history/` are used for persistence and frontend display only.

## Base URL
```
http://localhost:8000
```

## Endpoints

### 1. Send Chat Message
**POST** `/chat`

Handles user queries. The server sends only the latest user input. LangGraph checkpointer restores prior context by `session_id` internally, then routes through intent analysis -> optional SQL hard-filter branch -> collaborative filtering -> diversity -> summarization.

#### Request Body (JSON)
| Field | Type | Description | Required |
|-----------|--------|----------------|----------|
| `user_input` | string | The message from the user | Yes |
| `session_id` | string | Optional session ID for thread tracking | No (default: "default") |

**Example Request:**
```json
{
  "user_input": "I want a 2020 action movie.",
  "session_id": "user123"
}
```

#### Response Body (JSON)
| Field | Type | Description |
|-----------|--------|----------------|
| `response` | string | The final response generated by the Summarizer Agent. |
| `intent_data` | object | Diagnostics/metadata extracted during intent recognition. |

**Example Response:**
```json
{
  "response": "Here are some awesome 2020 Action movies for you: [Movie 1], [Movie 2]...",
  "intent_data": {
    "intent": "recommendation",
    "hard_filters": {
      "genre": "Action",
      "year": "2020",
      "min_rating": null
    },
    "response": null
  }
}
```

### 2. List Saved Sessions
**GET** `/chat/sessions`

Returns all locally saved sessions in `chat_history/` for frontend session list rendering.

**Example Response:**
```json
[
  {
    "session_id": "user123",
    "updated_at": "2026-03-31T08:20:43.832211+00:00",
    "message_count": 18,
    "file": "user123.json"
  }
]
```

### 3. Get One Session History
**GET** `/chat/history/{session_id}`

Returns the complete conversation history for one session (for frontend chat replay).

**Example Response:**
```json
{
  "session_id": "user123",
  "updated_at": "2026-03-31T08:20:43.832211+00:00",
  "message_count": 18,
  "messages": [
    {
      "type": "human",
      "data": {
        "content": "I want a 2020 action movie.",
        "additional_kwargs": {},
        "response_metadata": {},
        "type": "human",
        "name": null,
        "id": null,
        "example": false
      }
    }
  ]
}
```

## Running the API
From the root directory:
```bash
python main.py
```
Or via uvicorn directly:
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Swagger UI will be available at `http://localhost:8000/docs`.
